# Шатило Михаил 231-323

Веб-приложение для первой лабораторной работы по цифровому представлению изображений.
Приложение открывает изображения PNG, JPG и GB7, показывает их на `canvas`, отображает
основные параметры в строке состояния, позволяет скачать результат в любом из трех форматов,
управлять цветовыми каналами и считывать цвет пикселя инструментом «Пипетка».

## Ссылка

- Репозиторий: https://github.com/FrontendCourseMP/photoshop-mihailshat
- GitHub Pages: https://frontendcoursemp.github.io/photoshop-mihailshat/

## Возможности

- загрузка PNG, JPG и собственного формата GrayBit-7;
- отрисовка изображения на HTML5 `canvas`;
- сохранение текущего изображения в PNG, JPG и GB7;
- собственный кодер и декодер GB7 без библиотек обработки изображений;
- строка состояния с шириной, высотой и глубиной цвета;
- панель каналов с миниатюрами и включением/отключением каналов;
- инструмент «Пипетка» с RGB и CIELAB для выбранного пикселя;
- инструмент «Уровни» с гистограммой, линейным/логарифмическим режимом,
  настройками Master и отдельных каналов, предпросмотром и применением;
- адаптивный интерфейс для широких и узких экранов.

## Тестовые изображения

Тестовые GB7-файлы из задания лежат в корне проекта:

- `gradient-half-mask.gb7` - 32x32, изображение с маской;
- `kapibara-mask.gb7` - 1200x1010, изображение с маской;
- `vertical-kapibara.gb7` - 1080x1920, вертикальное изображение без маски.

Они также доступны в боковой панели приложения, чтобы быстро проверить декодер и
отрисовку на `canvas`. PNG и JPG можно проверить через кнопку открытия файла.

## Формат GB7

Формат GrayBit-7 хранит 12-байтовый заголовок и один байт на каждый пиксель. В младших
7 битах находится значение серого цвета, старший бит используется как маска, если в
заголовке включен соответствующий флаг.
